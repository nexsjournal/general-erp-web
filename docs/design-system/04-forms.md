# 04 · 表单系统（Forms）

> 适用于：新建/编辑单据、设置页、登录页。ERP 单据字段多，**密度与防错**优先。

## 1. 布局

- **Label 置于输入框上方**（不做左侧两栏 label）：
  - label：14px/400 `--erp-text-2`，距输入框 6px；必填加 12px `*`（error 色，紧跟文字后）；
  - 字段间距 16px；分节用 16px/500 `--erp-text-1` 小节标题（可带 16px 图标）+ 下方 12px 分割线；
- 单列纵向为默认；≥1440px 且字段短（≤8 字）可 2 列，列间距 16px；**长文本/表格型字段（备注、行项目）永远整行**；
- 表单底栏（新建/编辑页）：sticky 底边，白底 + 顶部 1px 分割线，按钮右对齐：「保存并继续 / 保存 / 取消」。

## 2. 输入框（Input）

| 状态 | 样式 |
|---|---|
| 常态 | 高 32px（紧凑）/ 40px（常规），白底，1px `--erp-border-1`，圆角 6px，文本 14px |
| Hover | 边框 `--erp-border-2` |
| Focus | 边框 `--erp-primary` + 外圈 3px `rgba(37,99,235,0.12)` 光环 |
| 禁用 | 底 `--erp-bg-muted`，文本 `--erp-text-disabled` |
| 错误 | 边框 `--erp-error` + 光环 `rgba(245,63,63,0.12)`；下方 12px error 文字（距输入框 4px），**输入时即时清除** |
| 只读 | 无边框无底，文本 `--erp-text-2`（系统生成字段如单号） |

- 占位符：`--erp-text-3`，只给格式提示（如 `jane@example.com`、`YYYY-MM-DD`），不重复 label；
- 前缀/后缀（货币符号、单位）：13px `--erp-text-3`，与文本间距 6px；
- 行内图标（搜索/日历/清除）：16px `--erp-text-3`，右侧 10px 内边距；可清除字段有值时显示 16px × 圆底清除按钮。

## 3. 控件

| 控件 | 规范 |
|---|---|
| Select 下拉 | 与输入框同规格；列表行高 36px，hover `--erp-bg-hover`，选中 `--erp-primary-lighter` + 16px 对勾；支持搜索的顶部带 32px 搜索框；空结果 12px 说明 |
| 多选（multi-select） | 选中项以 pill 展示在框内（12px pill，`--erp-primary-light` 底），可逐个 × 移除 |
| Checkbox | 16px 圆角 4px；选中 primary 底白勾；label 14px 间距 8px；整行可点 |
| Radio | 16px 圆；选中 primary 描边 + 内点 8px |
| Switch | 40×22px，选中 primary 底；用于「是否启用」类二元设置 |
| DatePicker | 输入框 + 日历弹层；今天加圆圈描边，选中 primary 底白字；范围选两段显示起止 |
| 数字/金额 | 右对齐；千分位；货币前缀；步进 ± 按钮仅数量类（金额禁用步进防误触） |
| 富文本/备注 | 最小高 80px，聚焦时展开；工具栏 16px 图标，仅保留 加粗/列表/链接 |
| 行项目表格（子表） | 表头 12px `--erp-bg-muted`；行高 40px；「添加行」为整行虚线 1px `--erp-border-1` 按钮区（hover primary 浅底）；行内删除图标按钮 16px |

## 4. 校验与反馈

- 时机：**失焦校验**为主，提交时全量；错误字段滚动定位到第一个错误处；
- 文案：12px，`{字段} + 具体原因`（「金额不能为负数」，不写「输入不合法」）；
- 联动字段变化（如公司 → 币种）：受影响字段立即重算并短暂 focus 高亮（200ms primary 光环渐隐）提示用户注意。

## 5. 登录页表单（特化）

- 卡片居中：宽 360px，上留白 15vh；
- 主按钮全宽 40px；次操作（邮箱链接登录）为整行 Secondary 按钮紧随其下；
- 「忘记密码？」13px tertiary 右对齐于密码字段下方；
- 错误横幅：卡片顶部，error 浅底圆角 8px，图标 + 13px 文本，出现时表单 200ms 下移（见 06-motion）。
