# 05 · 交互系统（Interaction）

## 1. 总则

1. **即时反馈**：任何操作 ≤100ms 内必须有可见响应（hover 变色/按下态/骨架屏）；
2. **可逆优先**：可撤销的操作不弹确认框（删除行项目→toast 内提供「撤销」，5s 有效）；不可逆操作（删除单据、审批）必须确认弹窗；
3. **就地处理**：能行内解决的不上浮（行内编辑、行内校验），打断层级从小到大：inline → toast → 弹窗 → 全屏；
4. **状态守恒**：切换页面/Tab 返回时保留滚动位置、筛选条件、未保存输入（表单草稿 30s 自动暂存 localStorage，提示「已暂存」）；
5. **一致优先**：相同语义全站同一交互模式（如「更多操作」永远在行尾 16px 点状图标按钮）。

## 2. 反馈层级

| 层级 | 组件 | 场景 | 自动消失 |
|---|---|---|---|
| L1 行内 | 字段校验、计数更新 | 输入即时 | 输入即清 |
| L2 Toast | 保存成功、复制成功、轻量错误 | 不阻断操作 | 3-5s |
| L3 弹窗 | 确认、必填信息收集、审批意见 | 需决策 | 手动 |
| L4 通知中心 | 异步结果（导入完成、支付回调） | 不要求立即处理 | 手动已读 |

规则：成功 toast 用于「值得告知」的完成（保存/提交）；**高频操作（如行内状态切换）只给行内视觉变化，不出 toast**（避免刷屏）。

## 3. 容器状态机（每种列表/图表/表单必须定义 5 态）

| 状态 | 表现 |
|---|---|
| Loading | 骨架屏（结构同真实内容，微光 1.2s 循环）；>3s 追加「加载较慢」12px 提示 |
| Empty | 图标 + 「暂无{对象}」+ 原因/下一步（「创建第一张采购订单 →」） |
| Error | 图标 + 简述 + 「重试」按钮；网络错误与权限错误文案区分 |
| No Permission | 「无权限查看」+ 申请入口（有审批流时） |
| Normal | 内容 + 刷新入口（表格右上角 16px 刷新图标，点击 600ms 旋转动画） |

## 4. 键盘（Keyboard）

| 按键 | 行为 |
|---|---|
| ⌘K / Ctrl+K | 全局搜索（顶栏聚焦，弹层式结果：单据/单据号/客户） |
| Esc | 关闭最上层弹层/下拉/聚焦态 |
| Enter | 表单提交（多行字段除外）；列表搜索确认 |
| Tab / Shift+Tab | 按视觉顺序；弹层内焦点圈定（focus trap） |
| ↑↓ + Enter | 下拉列表选择 |
| N | 列表页新建（单据列表上下文内） |

- 所有可交互元素可见 focus 环（3px `rgba(37,99,235,0.4)` 外圈），键盘导航时不隐藏。

## 5. 列表/单据典型流程

- **筛选**：顶栏「筛选」按钮 → 弹层字段+条件；激活条件以 pill 展示在列表上方（可单个 × 移除，「清除全部」）；
- **排序**：点列头切换 升→降→默认，激活列头图标 primary；
- **批量操作**：勾选后列表顶部出现操作条（已选 N 条 + 操作按钮 + 取消）；未勾选隐藏；
- **导出**：表格右上 16px 导出图标 → CSV/Excel 选择；大数据量异步导出走通知中心；
- **行操作**：行尾「⋯」16px 按钮 → 下拉（打开/复制/删除…），危险项红色且与其余项 1px 分割线隔开。

## 6. 错误与异常页

| 场景 | 处理 |
|---|---|
| 401 会话失效 | 跳转登录页并保留原目标地址，登录后回跳；toast「登录已过期」 |
| 403 无权限 | 页面级空态（锁图标 + 申请入口） |
| 404 | 图标 + 「页面不存在」+ 「回首页」按钮 |
| 500 / 网络 | 错误页（图标 + 简述 + 重试 + 错误 ID 12px 供反馈） |
| API 超时（>10s） | 按钮 loading 持续，追加可取消（「取消」text-danger） |

## 7. 文案（Copy）

- 动词开头（「保存」「导出」「删除订单」），不用「确定」表达动作；
- 按钮文字 ≤ 6 字；弹窗标题说事（「删除 3 张采购订单？」+ 补充一行后果说明）；
- 数字/单号保留原始格式（不本地化单号）；日期格式随语言（zh: `YYYY-MM-DD`，12px 辅助显示星期）。
