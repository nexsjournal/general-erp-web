# 07 · 图表与数据展示（Data Visualization）

## 1. 数据展示层级

1. **KPI 卡**（结论先行：当前值 + 环比）→
2. **趋势图**（线/柱：随时间变化）→
3. **构成图**（环/堆叠：占比）→
4. **明细表**（精确值、可导出）。

- 一屏 KPI ≤ 4-6 个；图表 ≤ 2-3 个；其余进下钻页；
- 每张图必须有「标题（16px/500）+ 时间范围控件（Segmented：今日/7天/30天/自定义）+ 数据更新时间（12px `--erp-text-3`，右上）」。

## 2. KPI 卡（参考图核心元素）

结构（自上而下）：

```
[13px 次要色标签（可带 16px 图标/来源徽标）]
[24-32px/600 数字 tabular-nums]
[涨跌徽章  ↑ +12.38%   vs 上期  12px 次要色]
```

- 数字字号：常规 24px，单卡强调 32px；千分位；货币用符号前缀（¥）；
- 涨跌徽章：pill，12px/500，浅底深字（好=success 浅底 / 差=error 浅底）；「vs 上期」文案 12px `--erp-text-3`；
- 环比口径固定为「上一等长周期」，tooltip 解释口径（「较上 7 天」）；
- 无数据：数字显示 `--`，隐藏徽章；
- 可下钻：整卡 hover 边框加深 + 右下 12px 箭头图标出现。

## 3. 折线图（Line / Area）

- 线宽 2px，`--erp-chart-1` 起；数据点默认**不画圆点**，仅 hover 时 4px 白底描边点 + tooltip；
- 面积填充：主色 12% → 0% 垂直渐变（参考图 Revenue 曲线）；
- 网格：水平虚线 1px `--erp-border-light`（4-6 条）；**不画竖网格线**；
- Y 轴：0 起（面积图）或自动区间（纯折线，上下留 10% 余量）；刻度标签 12px `--erp-text-3`，缩写（1.5k / 2.3M）；
- X 轴：按数据密度 4-8 个刻度，日期格式随粒度（日: `MM-DD`，月: `M月`，年: `YYYY`）；
- 多图例 ≤ 4 系列，超出合并「其他」或改分面；
- Tooltip：跟随最近数据点（垂直参考线 1px 虚线 `--erp-border-2`），深色底 `rgba(29,33,41,0.92)` 白字圆角 6px，内容 = 日期（12px 次要）+ 各系列「点 + 名称 + 值（13px/600）」，参考图 1 样式。

## 4. 柱状图（Bar）

- 柱宽 : 柱距 ≈ 2 : 1；圆角仅顶部 2px；
- 分组柱（对比两系列）：系列色 chart-1 / chart-2，同组柱间距 2px，组间距 8px；
- 堆叠柱（参考图 2 Budget）：**系列顺序固定**（不随数值排序跳动），底部系列为主色；
- 柱顶数值标签默认关闭，hover tooltip 提供；
- 横向柱（类别名长时）：类别名左对齐 13px，数值右端 13px/500。

## 5. 环形 / 饼图（Donut）

- **默认环形**（中心放总量或主指标，参考图 2 Spending Summary）：环厚 ≈ 半径的 22%；
- 扇区 ≤ 6，其余合并「其他」（固定灰色 chart-7）；
- 扇区间 2px 白缝；
- 标签：图例放右侧（点 + 13px 名称 + 百分比 13px/500 + 数值 13px 次要），不放扇区上；
- 半圆 Gauge（参考图 3 Payroll）：用于「进度/完成度」单指标，≤ 3 段，中心大数字。

## 6. 表格与图表的分工

| 需求 | 用 |
|---|---|
| 精确值 / 排序 / 筛选 / 导出 | 表格 |
| 趋势 / 对比 / 占比 | 图表 |
| > 10 行且需要逐项核对 | 表格（图表只做概览，附「查看明细 →」） |

## 7. 通用规则

- 空数据：图表区显示 40px 线性图标 + 「暂无数据」，不画空坐标系；
- 加载：骨架（矩形块近似图形轮廓）；
- 单位一致：同图同单位，换算（元→万元）在标题/轴标注；
- 打印/PDF 报表：白底黑字优先，色彩仅保留语义色，图表改静态快照。
