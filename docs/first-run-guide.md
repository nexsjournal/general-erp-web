# 首次访问指南：登录页与初始配置

> 说明访问系统时看到的「登录页」和「首次配置向导」上每个元素的作用、为什么需要它们，以及登录后的首页是什么。

## 1. 登录页（/login）

| 元素 | 作用 | 为什么要有 |
|---|---|---|
| 邮件/用户名输入框 | 登录标识 | frappe 按**用户名（doc name）**匹配登录标识，默认管理员是 `Administrator`（全大写），邮箱 `admin@example.com` 无效。多用户体系下每个用户是一个 User 文档，标识即文档名 |
| 密码输入框 | 凭据 | 密码加盐哈希存储（bcrypt），配合 frappe 的 Session 机制维持登录态 |
| 忘记密码？ | 邮件重置 | 向账号绑定邮箱发送一次性重置链接。本地开发若无邮件服务，可用 `bench --site <site> set-admin-password` 重置 |
| 继续（主按钮） | 提交登录 | 成功后建立 Session（cookie 维持），跳转到 Desk |
| 通过邮箱链接登录 | 无密码登录 | 发一次性链接，点开即登录。适合不常登录的审批人，也用于「首次激活账号」场景 |
| 右上角语言选择器 | 切换界面语言 | 由 `Website Settings > show_language_picker` 控制是否显示。选择后写入 `preferred_language` cookie，按「cookie → 浏览器 Accept-Language → System Settings 全局默认语言」的优先级生效。本环境全局默认已设为中文（zh） |

### 登录相关的设计原因

- **一个服务进程承载多个站点（site）**：frappe 是多租户框架，同一套代码/数据库集群可挂多个站点（按域名或站点名区分）。登录页因此是「通用」的，不带具体业务 logo，站点差异（公司、科目表）在登录后才生效。
- **语言是请求级属性**：同一个人可以在不同浏览器/语言下使用系统，翻译按请求即时加载，不重启服务。

## 2. 登录后的首页（Workspace 索引页）

登录进入 Desk 后看到的图标网格页（12 个方块）是 **Workspace 索引**，不是业务页面本身：

| 图标 | 英文名 | 内容 |
|---|---|---|
| 框架 | Framework | 系统管理：用户、角色、权限、文档类型、调度任务等 |
| 组织 | Organization | 公司、部门、员工、岗位、出勤 |
| 会计 | Accounting | 总账：凭证、账户、日记账、财务报表 |
| 资产 | Assets | 固定资产、折旧 |
| 采购 | Buying | 供应商、采购订单、采购发票 |
| 生产 | Manufacturing | BOM、工作中心、生产计划、工单 |
| 项目 | Projects | 项目、任务、工时 |
| 质量 | Quality | 质检、质量审计 |
| 销售 | Selling | 客户、报价、销售订单、销售发票 |
| 库存 | Stock | 仓库、物料、出入库、盘点 |
| 委外 | Subcontracting | 外协加工 |
| ERPNext 设置 | Settings | 系统级参数：会计设置、库存设置、打印格式等 |

**Workspace（工作区）= 一个业务域的导航集合**：每个 Workspace 内部由 List（单据列表）、Report（报表）、Chart（图表）、Tree（树形结构）按业务动线编排。ERPNext 的导航不是传统菜单树，而是「先选域（Workspace），再在域内找东西」，好处是业务模块可整体增删（二开时我们的 `general_erp` 模块也可以注册自己的 Workspace）。

## 3. 首次配置向导（Setup Wizard）

### 触发条件

- 站点尚无公司（`tabCompany` 为空）且向导未完成时，登录后会引导进入；
- 完成后写入完成标记（`setup_wizard_completed_apps` 含 `erpnext`），不再打扰；
- 可随时重新进入调整（Desk 菜单搜索 Setup Wizard）。

### 向导各步骤与配置项

| 步骤 | 配置项 | 作用 | 为什么需要 |
|---|---|---|---|
| 1. 国家与语言（frappe 层） | 国家 | 时区、日期格式、默认税务模板 | 会计与税务规则强依赖国家；时区决定单据时间与调度 |
| | 语言 | 界面语言 | 多语言站点的基础设置 |
| 2. 关于你（Persona，v16 新增） | 为谁部署 / 团队规模 / 行业 / 现用系统 | 仅用于统计（telemetry）并按行业预选模块 | 降低选模块的认知成本；可跳过不影响功能 |
| | 模块勾选（会计/库存/生产/项目） | 决定重点模块 | 会计恒开，其余按需 |
| 3. 组织（Organization） | 公司名称 | 创建 Company 单据 | **公司是 ERPNext 所有财务单据的核心维度**：账户归属、损益核算、多公司对比都挂在它上面 |
| | 公司缩写 | 单据编号前缀（如 PI-0001 → QY-PI-0001） | 多公司环境下单据编号全局唯一 |
| | 会计科目表（Chart of Accounts） | 按国家选择预设科目模板 | 决定总账科目结构（收入/成本/资产负债科目树），建账一次、后续所有凭证走这套科目 |
| | 财务年度开始日 | 创建 Fiscal Year | 期间关闭、预算、报表区间都以财年为单位；不同国家习惯不同（如印度 4-1 开始） |
| | 生成演示数据（可选） | 创建一套可删除的示例业务数据 | 便于先探索系统再清掉；正式使用勿勾选 |

### 为什么这些配置不可省

- 没有公司 → 会计单据无法落账（凭证必须归属公司）；
- 没有财年 → 期间相关逻辑（期间校验、年结）无参照；
- 科目表是「建账动作」，事后更换成本极高，向导阶段确认是为了避免误建。

## 4. 上线前建议配置清单（Desk → ERPNext 设置）

| 设置 | 入口 | 说明 |
|---|---|---|
| 会计设置 | Accounting Settings | 默认账户、开票规则、成本中心策略 |
| 库存设置 | Stock Settings | 默认仓库、估值方法、盘点方式 |
| 销售/采购设置 | Selling / Buying Settings | 单据状态流、有效期、价格清单 |
| 打印格式 | Print Format Builder | 发票/订单 PDF 版式 |
| 用户与角色 | 框架 → 用户/角色 | 按岗位分配角色（如 Accounts Manager），权限由角色决定 |
| 集成 | Integrations | 邮箱（SMTP）、支付网关、Webhook |
