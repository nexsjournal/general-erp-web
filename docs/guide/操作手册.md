# 太康生物ERP 操作手册

> 写给第一次用这套系统的你。不假设你会 ERP，每一步都告诉你点哪里、填什么。
> 遇到问题先翻最后一章「常见问题」，大部分都写在里面了。

## 第 0 章 登录系统

**打开**：浏览器输入网址（本机测试 http://localhost:8002 ，正式部署后是你们的域名或 IP）。

**登录**：
1. 页面出现登录框，「邮件或用户名」填你的账号（管理员是 Administrator，普通员工是邮箱或用户名）
2. 「密码」填你的密码（首次登录用管理员发的初始密码）
3. 点「继续」

**登录进去后看到什么**：
- 最上面一条：系统名「太康生物ERP」+ 你的名字 + 右上角齿轮（改密码/语言）
- 左边一列：13 个功能模块（销售管理、采购管理、库存管理……）
- 右边：当前模块的具体功能按钮

**重要机制**（别困惑）：
- 你点左侧「销售管理」，右边显示的就是销售相关的单据入口——**左边是"房间"，右边是"房间里能办的业务"**
- 每个模块顶部有一行小字「流程：A→B→C」，告诉你这个模块业务按什么顺序做，照着点就行
- 闲置 8 小时没操作，再点会要求重新输密码——这是正常的防盗机制
- 点浏览器左上角返回，或者点左侧任意模块，都能随时切换，不会乱跳

**改自己的密码**：右上角你的名字 → 「用户参数」→ 改密码。你自己的事自己改，跟别人无关。

**下面一行模块卡片**：销售管理/采购管理/库存管理/财务管理/客户管理/产品管理/邮件中心/外贸管理/生产管理/组织管理/报表中心/系统设置/业务流程。点哪个进哪个。

**「业务流程」卡片**：全部业务的流程图画在一页上（销售两条主线+采购+库存），点任意节点直接跳到对应单据页面。新人培训就看这一页。

## 第 2 章 销售管理（最常用）

左侧「销售管理」。顶部流程条告诉你顺序：

**标准销售**：客户 → 商机 → 报价单 → 销售订单 → 交货单 → 销售发票 → 收款单 → （订单利润在报表中心看）

**外贸销售**：线索 → 客户 → 客户跟进 → 客户360 → 商机 → 报价单 → 销售订单 → 出运明细单 → 单证制作 → 收款单 → 订单利润

### 2.1 客户
1. 点「客户」→ 右上「添加」
2. 必填：客户名。其余（联系人/电话/地址）能填就填
3. 保存。客户就建好了，后面报价/订单都选它

**客户列表顶部三个视图**：
- 「我的客户」：分配给我的
- 「公海客户」：没人的，可以领走（点列表行→认领）
- 「热点客户」：最近有跟进的

### 2.2 商机
谈成没谈成的生意线索。点「商机」→ 添加 → 选客户、填预计金额、选状态（待批复/已批复/待回复）。

### 2.3 报价单
1. 点「报价单」→ 添加
2. 选客户 → 下面明细表加行：选商品、填数量、填单价
3. 合计自动算（元）。保存

### 2.4 销售订单（合同性质的单据）
1. 点「销售订单」→ 添加，或直接从报价单页点「创建销售订单」（一键带过来）
2. 选客户、加商品明细
3. **提交**（右下角「提交」按钮）。提交后订单进入审批流（如果配了审批）

### 2.5 交货 / 出库
1. 销售订单页 → 点「创建交货单」
2. 交货单提交后**库存自动减少**（系统自己扣，不用手动改库存）

### 2.6 销售发票（给客户开票）
1. 交货单页 → 「创建销售发票」
2. 提交 → 客户应付金额进入「应收账款」

### 2.7 收款（客户打钱了）
1. 点「收款单」→ 添加
2. 选客户、选要冲哪张发票、填实收金额（元）、选收款账户
3. 提交 → 应收减少

**整条链做完**：报价→订单→交货→发票→收款，库存和应收自动联动，报表中心「订单利润」能看到这单赚了多少钱。

### 2.8 外贸专属
- **出运明细单**：订单页「创建出运明细单」，填船期/港口/贸易术语
- **单证制作**：外贸管理→单证制作，按出运单选出，生成发票箱单等
- 出运状态会沿着 草稿→已订舱→已出运→已清关→已交付 逐级前进（不能跳级、不能倒退，系统管着）

## 第 3 章 客户管理

左侧「客户管理」。

| 功能 | 干什么 |
|---|---|
| 客户 | 客户档案（同 2.1） |
| 联系人 | 客户那边的联系人 |
| 客户跟进 | 每次电话/邮件/拜访记一条。公海客户长期没跟进会被系统收回公海 |
| 客户360 | 输入客户名，一页看全：联系人+订单+发票+回款+沟通记录 |
| 线索 | 陌生线索（网站留言会自动进来）。分配给业务员后变客户 |
| 商机 | 见 2.2 |

**跟进怎么做**：客户页点某客户 → 下面「客户跟进」加一条：方式（电话/邮件/拜访）+ 内容 + 下次跟进时间。

## 第 4 章 采购管理

左侧「采购管理」。流程：供应商 → 采购订单 → 采购收货 → 来料检验。

1. **供应商**：点「供应商」→ 添加，填供应商名/联系方式
2. **采购订单**：添加 → 选供应商 → 加商品明细 → **提交**（进审批）→ 审批人点同意
3. **采购收货**：采购订单页「创建采购收货」→ 提交 → **库存自动增加**
4. **验货单**：收货后可建验货单。合格→放行入库；不合格→生成退货待办、拦截入库
5. **采购发票**：收到供应商发票后录入，提交 → 进入「应付账款」
6. **付款**：财务管理→付款单，冲采购发票 → 应付减少

---

## 第 5 章 库存管理

左侧「库存管理」。流程：入库 → 库存余额 → 出库 → 统计/预警。

- **入库/出库单**：大多数情况不用你手动做——销售交货、采购收货会自动生成。这里主要用来处理"其他出入库"（领用/损耗/期初建账）
- **库存余额**：每个商品现在库里有多少，直接查
- **库存预警**：低于安全库存的商品自动列出来（报表中心也有）
- **仓库**：多仓库在这里维护

---

## 第 6 章 产品管理

左侧「产品管理」。流程：商品 → 商品组 → 计量单位 → 海关编码。

1. **商品**：所有要买卖的东西都先建商品。点「商品」→ 添加 → 商品名 + 规格 + 单位 + 默认售价/成本
2. **商品组**：分类（原料/成品/办公用品），方便筛
3. **计量单位**：个/箱/千克，建商品时要用
4. **海关编码**（HS Code）：外贸商品必填。不是所有商品都需要——传统内销产品、办公用品没有海关编码就留空，不影响使用

---

## 第 7 章 财务管理

左侧「财务管理」。流程：收付款 → 费用报销 → 发票管理 → 订单利润。

| 功能 | 干什么 |
|---|---|
| 收款单 | 客户给我们打钱（同 2.7） |
| 付款单 | 我们付钱给供应商 |
| 销售发票 | 开给客户的（同 2.6） |
| 采购发票 | 供应商开给我们的（同 4.5） |
| 费用报销 | 员工差旅/办公费用报销，走审批 |
| 科目表 | 会计科目，一般不用动 |
| 会计期间 | 账期设置，一般不用动 |

**老板看钱**：报表中心→利润表/资产负债表/应收/应付，点开直接有数（已配好当前会计年度，不会看到"请选择期间"）。

## 第 8 章 邮件中心

左侧「邮件中心」。流程：邮件工作台 → 邮件记录 → 邮箱账号 → 邮件模板 → 群发。

- **邮件工作台**：待处理/收件箱/草稿箱/已发送/待审批/已删除，跟 Outlook 一样用
- **邮箱账号**：把公司邮箱（IMAP/SMTP）接进来，系统直接收发。未配置时群发会记"部分失败"，属预期
- **邮件模板**：常用话术存模板，群发时套
- **邮件群发**：选客户+选模板+发送。有频率限制（每天上限/单收件人上限），防被封号
- **发送跟踪**：对方开了没、点了没，有记录

---

## 第 9 章 外贸管理

左侧「外贸管理」。流程：出运明细单 → 外贸单证 → 海关编码 → 贸易术语 → 港口 → 服务商。

- **出运明细单**：见 2.8
- **单证制作**：按出运单生成外贸单据
- **海关编码/贸易术语/港口/服务商**：基础资料。第一次用先建齐（HS 编码、FOB/CIF 等术语、常用港口、货代公司），后面出运时直接选

---

## 第 10 章 报表中心（看经营）

左侧「报表中心」。分四组：

**外贸组**：外销统计 / 订单利润 / 产品统计 / 出运明细单
**财务组**：收款统计 / 付款统计 / 费用统计 / 采购统计 / 利润表 / 资产负债表 / 应收账款 / 应付账款
**库存组**：库存余额 / 库存流水 / 库存盘点 / 库存预警 / 批次统计
**经营与运营**：公司数据报数 / 出运日志 / 员工统计 / 部门统计 / 群发效果

用法：点报表名 → 选日期范围（默认本期）→ 看数。右上角可导出 Excel/打印。

**老板日报三张**：公司数据报数（当天全公司动态）、外销统计（卖了多少）、利润表（赚了多少）。

## 第 11 章 组织管理（管人管权限）

左侧「组织管理」。流程：员工 → 部门 → 角色 → 岗位 → 工作流 → 审批。

### 11.1 加一个人
1. 「用户」→ 添加 → 填姓名、用户名、**选岗位**（销售/外贸专员/采购/库存/财务/总经理）
2. 系统按岗位自动给整套权限，**不用你逐个勾**
3. 生成密码发给本人（邮箱可留空）

### 11.2 权限不够怎么办
管理员给这个人**再加一个岗位**（一个人可多岗位，权限叠加）。比如业务员要偶尔看报表，就加个"总经理"或单独授权。

### 11.3 审批（谁审批什么）
- 「审批设置」页：三问向导——①哪些单据要审批 ②谁审批 ③多少钱以下免审批。答完自动配好
- 「审批任务」：待我审批的单据都在这，点「同意/驳回」
- 审批人必须对该单据有查看权限才能批（系统管着，防止批了看不懂）
- 超时没批会催办

### 11.4 员工/部门
- 「员工」：档案（部门/入职日期/岗位），和登录账号是两套东西
- 「部门」：组织结构

## 第 12 章 系统设置（管理员用）

左侧「系统设置」。一般员工看不到。

| 功能 | 干什么 |
|---|---|
| 公司 | 公司信息、Logo |
| 币种汇率 | 每日汇率录入（今日汇率卡用它）。支持批量 |
| 系统参数 | 公海回收天数等全局开关 |
| 打印格式/表头 | 单据打印样式（含单证打印） |
| 用户 | 账号管理（同 11.1） |
| 数据与备份 | 一键备份/备份列表/下载。每日凌晨 03:00 自动备份保留 14 天 |
| 登录日志 | 谁什么时候登录过，审计用 |

**备份怎么用**：「数据与备份」→ 看备份列表（每天一条）→ 下载。系统重装后拿备份文件恢复即可，数据不丢。

## 第 13 章 生产管理（一般用不到，先了解）

左侧「生产管理」。流程：生产计划 → 工单 → BOM。

适合有自己生产环节的企业：
- **BOM 物料清单**：一个成品由哪些料组成、各多少
- **生产计划/工单**：排产，领料、完工入库
- **生产任务单**：走审批

不做生产的企业（贸易/办公）这一模块放着不用即可，不影响其他模块。

## 第 15 章 常见问题

**Q：登录后怎么是英文？**
A：右上角头像→区域设置→语言选「中文」。之后全系统都是中文。

Q：金额为什么显示「492,000.00 元」而不是 ¥492,000？
A：按中国书写习惯，人民币就是数字+元。所有金额（列表/单据/报表/合计）口径统一。

Q：我提交了一个订单，怎么变成"审批中"了？我不能自己推进吗？
A：该单据配了审批流。等审批人（组织管理→审批任务）批完才能往下走。这是防绕过设计，审批中任何人（包括你）都不能直接提交。

Q：客户建了为什么订单里选不到？
A：确认客户保存了、名字对。列表页顶部筛选没被"我的客户"挡住的话，切「全部」。

Q：库存怎么自己变了？
A：正常。销售交货=减库存，采购收货=加库存，自动联动，不要手动改库存数字（手动改只在盘点/损耗时用出库入库单）。

Q：邮箱群发显示"部分失败"？
A：邮箱账号（系统设置→邮箱账号）没配真实 SMTP 时是预期行为。配上公司邮箱后正常。

Q：页面偶尔转圈/通知没实时？
A：本地开发环境实时通道未全开（socket.io），正式部署后消除。数据不受影响，刷新即可。

Q：闲置多久会要我重新登录？
A：8 小时。

Q：普通员工能看到别人的客户吗？
A：不能。客户按归属隔离，公海里的除外（公海就是给人领的）。

Q：管理员怎么给某人开权限？
A：系统设置→用户→找到那个人→加岗位（可多个）。岗位=整套权限包。

Q：系统重装/换机器，数据怎么办？
A：系统设置→数据与备份→下载最近备份。新环境装好后恢复备份即可。每日凌晨自动备份，最多丢一天。

Q：网站上的留言会进系统吗？
A：会。官网留言（/website-lead）自动生成线索，进客户管理→线索，可分配给业务员。同一 IP 每小时限 5 条防刷。
